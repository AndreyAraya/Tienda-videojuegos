# The GameVault

A full-stack web application inspired by digital video game platforms such as Steam. The system allows users to browse and manage video games through an interactive store and personal library experience.

## Technologies Used
- PHP
- Laravel
- MySQL
- JavaScript
- HTML
- CSS

## Features
- User login system
- Admin mode for store management
- Add, edit, and delete video games
- Personal game library management
- Search and filtering system for games
- Community and support sections
- Database integration with MySQL

## Description
This project was developed as a practice application focused on backend development, database management, and full-stack web application structure. The platform simulates a digital game store where users can manage their personal library and administrators can manage the available games in the store.

## Learning Objectives
- CRUD operations with database integration
- User authentication and role management
- Dynamic content handling
- RESTful application structure
- Frontend and backend integration
